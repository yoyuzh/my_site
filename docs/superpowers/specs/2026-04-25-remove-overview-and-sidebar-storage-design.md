# 删除总览页并在侧边栏展示网盘已用大小

## 目标

- 彻底移除用户侧的 `总览 Overview` 页面入口。
- `dashboard` 默认进入页从 `/dashboard/overview` 改为 `/dashboard/files`。
- 在左侧边栏的 `管理面板 Admin` 上方新增一个存储信息区域，展示当前网盘已用大小。
- 不新增后端接口，直接复用现有容量查询能力。

## 非目标

- 不改动后台管理面板路由。
- 不改动文件页、任务页、分享页、回收站、快传页的业务逻辑。
- 不重做整个侧边栏视觉结构，只在现有结构内调整入口和补充信息卡片。
- 不在本轮展示更复杂的容量明细图表。

## 页面与路由调整

### 总览页处理

- 移除侧边栏中的 `总览 Overview` 导航项。
- `frontend/src/App.tsx` 中：
  - 删除 `/dashboard/overview` 用户路由。
  - 将 `/dashboard` 的默认跳转从 `overview` 改为 `files`。
- 后台无权限时的跳转目标也从 `/dashboard/overview` 改为 `/dashboard/files`，避免落到已删除页面。

### 侧边栏信息区

- 在左侧边栏靠下位置、`管理面板 Admin` 按钮上方增加一个轻量信息卡片。
- 信息卡片展示：
  - 标题：`网盘已用`
  - 主值：`usedBytes`
  - 次级说明：可同时展示 `totalBytes`，例如 `共 200 GB`
- 数据来源：现有 `useUserCapacity`。
- 加载时显示简短占位文案，例如 `正在读取容量信息...`。
- 获取失败时显示保守文案，例如 `容量信息暂不可用`。

## 交互与视觉原则

- 侧边栏仍以导航为主，存储信息卡片只作为辅助信息，不压过导航项和管理面板按钮。
- 信息文案使用用户语言，不显示接口名或技术字段名。
- 如果容量数据可用，优先突出“已用大小”，而不是“剩余大小”。

## 实现边界

- 主要改动文件预计为：
  - `frontend/src/App.tsx`
  - `frontend/src/components/workspace/WorkspaceSidebar.tsx`
- `frontend/src/pages/Overview.tsx` 可以保留文件但不再挂路由；本轮目标是移除用户入口与默认访问路径，不强制删除物理文件。

## 验证标准

- 登录后访问 `/dashboard` 会进入文件页。
- 左侧边栏不再出现 `总览 Overview`。
- 左侧边栏底部能看到网盘已用大小。
- `管理面板 Admin` 仍保留在该信息区下方。
- `npm run lint` 通过。
